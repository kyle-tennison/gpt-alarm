# `gpt-alarm`

<img width="1040" height="612" alt="image" src="https://github.com/user-attachments/assets/a8fa0652-b4f2-4cac-93f4-d38fed49628d" />



An alarm clock that only goes off once you're actually out of bed. 

GPTs are advantageous for this task because they don't need to be trained for each specific environment. But we gotta do everything locally so we're not just giving openai a livestream of us sleeping. 

This is intended to run on a raspberry pi with some sort of tpu hat.
